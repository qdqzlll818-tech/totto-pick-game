# 水果局完善计划

## 目标

在不破坏现有存档、点击穿透、暂停菜单与摇一摇功能的前提下，把第三关做成可辨识的“夏日水果篮”终局。

## 已确认设计

- 关卡总量保持 126 件，每一种数量均为 3 的倍数。
- 使用 13 种统一风格的本地 3D 水果素材。
- 水果托托沿用草帽、草莓装饰和手拿西瓜的已确认造型。
- 视觉采用清爽、低饱和的日系夏日野餐配色，不使用荧光色。
- 游戏容器从通用黑锅改为浅色藤编果篮，并保留密集立体堆叠。
- 完成关卡后解锁“夏日水果帽”皮肤。
- 露出的底层物件仍可点击，完全遮住的物件需要翻动后才能点击。

## 实施

1. 为水果托托增加稳定、可缓存的发布文件名，并让任务、棋盘、衣柜共用。
2. 为关卡配置补充场景摆件、容器描述和专属开场文案。
3. 为水果局增加独立的野餐垫、藤编果篮、果篮内衬和水果高光样式。
4. 增加配置与资产回归测试，先验证失败，再实现。
5. 运行完整测试与浏览器核查后发布到 GitHub Pages。
